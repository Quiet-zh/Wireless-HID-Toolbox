# 测试说明

## 运行

```bat
python -m unittest discover -s tests -v
```

不依赖真实鼠标/键盘，也不需要管理员权限。GUI 相关功能需要手动验收。

当前：**471 个自动化用例**。

> 需要 `tkinter`（GUI 相关用例会自动跳过无 tkinter 的环境），
> 不需要 vosk / sherpa-onnx / websockets / numpy 等可选依赖——
> 引擎相关用例用临时目录伪造模型结构，并 mock 掉缺失的包。

## 测试隔离

- 配置测试使用 `tempfile`，不会写真实 `%APPDATA%` 配置。
- 设备删除/类型测试使用假配置字典，不会改本机设备列表。
- 主题测试只测颜色数据，不创建 Tk 窗口。
- GUI 用例在 `setUp`/`tearDown` 创建并销毁临时 Tk 根窗口，不触碰真实配置。

## GUI 手动验收

### 主面板

- [ ] 主题按钮：黑夜 → 白天 → 黑夜，标题、卡片、按钮、滚动条同步
- [ ] 点击设备卡片的名字：名字写入剪贴板，标签短暂显示「✓ 已复制」后恢复；
      关闭面板后再粘贴仍然有效（Windows 用系统剪贴板直写）
- [ ] 内容不足时右侧滚动条隐藏；增加卡片/缩小窗口后出现
- [ ] 关闭按钮行为：仅主界面 / 所有可见窗口 / 完全退出
- [ ] 托盘未运行时，非"完全退出"的关闭先询问是否常驻
- [ ] 无托盘关闭最后窗口时完全退出
- [ ] 最小化：托盘 / 正常任务栏两种模式
- [ ] 退出托盘后右下角变为"托盘已退出"，不卡在"正在退出"

### 设置

- [ ] 设备类型下拉：鼠标 ↔ 键盘，重启后保持
- [ ] 删除设备：面板/托盘同步移除，扫描不自动恢复
- [ ] 恢复已删除：设备重新出现
- [ ] 设置窗口与协议表随主题切换

### 鼠标键盘测试

- [ ] 多个鼠标/键盘可切换监听设备
- [ ] 键盘 104 键高亮、Caps/Num/Scroll、rollover、历史、重置

- [ ] 组合事件/宏定义可增删改步骤、上下移动、每步设置等待毫秒
- [ ] 添加/修改/删除后立即写 `mouse_map.json`；重启界面仍在
- [ ] 配置窗口打开时后台映射暂停，关闭后状态回到「运行中」
- [ ] 单鼠标：把侧键映射为 `ctrl+c`，在记事本按侧键只粘贴一次、不再后退

- [ ] 魔声语音键绑定语音输入：点好输入框，按住语音键说话，松开只键入一次

- [ ] 状态文件 `mouse_map_status.json` 显示钩子/Raw/语音与最近动作

## 新增测试约定

- 纯数据/协议测试放在 `tests/`，命名 `test_*.py`。
- 会写配置的逻辑必须 patch `tray_common.load_config/save_config` 或使用临时路径。
- GUI 绘制逻辑优先抽成可测试的颜色/布局数据；Tk 创建测试不作为必跑项。
- 新增滚动区域一律复用 `ui_common.attach_auto_scrollbar`，不要手写常驻滚动条。
