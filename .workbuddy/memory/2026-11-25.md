# 2026-11-25

## 登记 Monster AiMouse（v1.3.0）

- 设备：2.4G Monster 人体工学鼠标，VID `0x248A`（Maxxter）/ PID `0x60AB`，产品名 AiMouse，已连接。
- 实测结论：
  - HID 枚举出 6 个接口；标准头文件无电量 Usage（鼠标口仅 X/Y/wheel，FFEF 私有口仅 `0xFFEF:0x1/0x3`）。
  - `generic_scan.py --list` 显示「标准 HID 电量（回退）」是**误报**（按 Feature 长度推断），`--json` 实际读不到电量。
  - `0xFF91` 私有接口有主动上报报文（形如 `0c 4d 06 69 00 64 04 01 00 4c`），字段含义未确认，未臆造协议。
- 改动：
  - `device_registry.py`：PRIMARY 加入 `248A:60AB` = Monster AiMouse / mouse / order 25；`infer_kind` 增加 aimouse/monster 关键词。
  - `mouse_events.py`：known_kind / known_label 同步登记，测试面板可识别。
  - `version.py` + `version_info.txt`：1.2.1 → 1.3.0。
  - `README.md`、`docs/DEVICE_CONFIG.md`、`docs/PACKAGING.md`、`CHANGELOG.md`：同步设备、配置示例、版本与「电量待抓包」说明。
  - `tests/test_registry.py`：新增 `test_aimouse_registered`，测试数 50 → 51。
- 验证：系统 Python 3.15（自带 tkinter）跑完整套件 51/51 通过；临时 APPDATA 下 `known_devices()` 与 `config.json` 均出现该设备。
